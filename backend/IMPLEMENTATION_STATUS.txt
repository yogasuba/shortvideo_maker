## Key Changes

```
FILE: backend/font_downloader.py
─────────────────────────────────────────────────────────────
BEFORE:
  if file_size > 100000:  # 100KB threshold
      logger.info("✓ Font available")
  else:
      logger.warning("Font corrupted")  # ← 78KB gets deleted!
      font_path.unlink()  # ← DELETE FONT!

AFTER:
  if font_path.exists():  # Just check existence
      logger.info(f"✓ Font available: {font_name}")

RESULT: Small fonts (78KB) accepted, never deleted


FILE: backend/complex_script_renderer.py
─────────────────────────────────────────────────────────────
BEFORE:
  # Check custom, then system, then English
  # Silent fallback for any language

AFTER:
  # Check custom fonts
  # For complex scripts: HARD ERROR if not found
  if language in self.COMPLEX_SCRIPTS:
      raise RuntimeError("No custom font found...")

RESULT: No system font fallback for ta/hi/ar


FILE: backend/main.py
─────────────────────────────────────────────────────────────
BEFORE:
  drawtext_filter = f"drawtext=...fontfile='{font_path}':..."
  # No harfbuzz shaping specified

AFTER:
  if language in ["ta", "hi", "ar"]:
      drawtext_filter = f"drawtext=...shaping=complex"
      logging.info(f"✓ Using custom {language} font with HarfBuzz")

RESULT: Explicit HarfBuzz, clear logging


FILE: backend/main.py (PIL Fallback)
─────────────────────────────────────────────────────────────
BEFORE:
  if ffmpeg_failed:
      return await self._create_scene_with_pil_fallback()

AFTER:
  if ffmpeg_failed:
      if language in ["ta", "hi", "ar"]:
          raise RuntimeError("FFmpeg required for complex scripts")
      else:
          return await self._create_scene_with_pil_fallback()

RESULT: PIL never used for ta/hi/ar
```
